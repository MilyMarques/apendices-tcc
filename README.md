# Material suplementar

Esta pasta reúne os apêndices gráficos do TCC. Cada subpasta corresponde a uma análise feita no Módulo SNP2GENE e GENE2FUNC do FUMA GWAS, indo de B até H. O apêndice A é o repositório principal com os dados, figuras e scripts mais importantes do trabalho. Para acessá-lo: [Apêndice A](https://github.com/MilyMarques/dados-tcc-arquitetura-genetica-insonia)

Os documentos estão em formato PDF. 

Os apêndices não substituem as tabelas integradas do repositório. Eles documentam as saídas gráficas dos jobs FUMA SNP2GENE selecionadas para consulta suplementar, considerando que cada *job* do FUMA em ambos os módulos gera muitos gráficos e tabelas.

- Apêndice B: Gráficos suplementares do módulo SNP2GENE de Hammerschlag *et al* 2017.
- Apêndice C: Gráficos suplementares do módulo SNP2GENE de Lane *et al* 2019.
- Apêndice D: Gráficos suplementares do módulo SNP2GENE de Jansen *et al* 2019.
- Apêndice E: Gráficos suplementares do módulo SNP2GENE de Watanabe *et al* 2022.
- Apêndice F: Gráficos suplementares do módulo SNP2GENE do *job* FinnGen R13.
- Apêndice G: Gráficos suplementares do módulo SNP2GENE dos *jobs* ukb-a-13 (Neale Lab; job 761601) e ukb-b-3957 (PHESANT/MRC-IEU; job 761609), *datasets* do *OpenGWAS*.
- Apêndice H: Gráficos suplementares do módulo GENE2FUNC.
